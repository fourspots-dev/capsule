竞态验证点预期
new_tab 创建中用户切走组创建、attach、UI 订阅新标签加入原 Workspace，但 UI 保持用户最终选择
A→B→C 快速激活resolve 交错返回最终只订阅 C，旧 Projection 不得覆盖
切换时成员集合变化membership revision过期工具返回 stale，不作用于新成员
任务运行中标签移出组当前和后续工具目标已开始操作完成或安全中止，后续拒绝
关闭 active 成员下一 active tab优先同组下一个成员，不切到组外
竞态测试必须在 E2E 中注入异步延迟，不能只依赖顺序单元测试。

TOOL-08close_tab 关闭组外 CTARGET_OUTSIDE_WORKSPACE
  • 同一 target 同时最多一个可变操作。
  • 只读并行不得改变 active target。
  • 结果携带 sessionId、workspaceKey、targetId。
  • 审批 digest 包含 Workspace revision 与 target，防止批准后目标变化。

ID检查预期
PORT-01Core 静态依赖扫描src/core 不引用 chrome/tabs/tabGroup/groupId/debugger
PORT-02TUI 构建只加载 TerminalWorkspacePort，不包含 Chrome Gateway
PORT-03TUI 单会话启动生成一个 Standalone Workspace，无需 tab/group 字段
PORT-04Chrome 启动只加载 ChromeWorkspacePort 和 Browser ToolPack
PORT-05Session Snapshot 互通同一 Snapshot 可由 Chrome/TUI 读取，Chrome binding 不入库
PORT-06多端写同一 Sessionlease/fencing 阻止并发破坏

禁止

Core 导入 ChromeProvider，SessionSnapshot 存 tabId/groupId，TUI 注册 new_tab。

允许

Adapter 提供 opaque targetId；Browser ToolPack 独立注册；各端只负责自己的 scope 映射。

检查项预期

@ 菜单当前组和其他标签分区；组内切换不换 Session

8. 发布门禁

功能

组内多 target 共享 Session；组外自动独立；Agent 可在组内新开与切换。

隔离

组外工具拒绝；快速切换不串消息、审批、草稿和任务状态。

跨端

Core 和 Session Snapshot 无 Chrome 依赖；TUI standalone 构建通过。

  • Registry 单元测试覆盖所有作用域转换与成员状态。
  • Tool contract 覆盖组内/组外和 stale membership。
  • 至少 3 个真实 Chrome E2E：组内协作、组外隔离、Agent 建组。
  • 至少 2 个并发测试：快速标签切换、运行中成员变化。
  • v1 映射迁移、全量清理和 TUI 隔离均有回归测试。
  • 不引入跨组审批越权、内部 ID 泄漏或历史消息自动合并。
M1-M4 已实现并通过 Core 边界检查与 Chrome E2E；TUI/Web Adapter 仍是后续端口接入工作。
