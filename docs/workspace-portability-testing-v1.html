REQ-WORKSPACE-001 / PORTABLE WORKSPACE CAPSULE / TEST DESIGN V1

Portable Workspace Capsule
跨宿主连续性测试方案

证明同一 Workspace 在导出、传输、导入和恢复后仍保持内容、会话、任务、版本、Artifact、证据与应用动作要求的一致性；任何无法迁移的状态都必须显式失败或降级，不能静默丢失或误报成功。

1. 测试策略与风险

必须证明

  • 项目、Session、Task、VCS、Artifact 和 Evidence 来自同一 generation。
  • 跨宿主导入后，同一 Session 可从最后安全边界继续。
  • 无法迁移的运行资源被终止并留下明确对账状态。
  • 缺少 Artifact、Git 对象、工具链或路径兼容性时不会静默吞掉。
  • 新宿主上的旧测试证据不会伪装成当前环境的验证结果。

最高风险

  • 导出文件树完整，但 Session 指向不存在的 Artifact。
  • VCS head 存在，snapshot object 丢失。
  • 导入一半后覆盖原 Workspace。
  • 宿主绝对路径、PID、Secret 进入 Capsule。
  • Windows 大小写/保留名使两个文件合并或覆盖。
  • 把运行中 Process/PTY 当成可恢复状态。
P0：静默数据丢失、半激活导入、跨宿主伪造完成、Secret 进入 Capsule、悬空 Agent 引用、路径越界任一出现即阻止发布。

4. 测试夹具

CapsuleFixture

  • 最小 Capsule、完整 Capsule、旧 schema、未知可选分区。
  • 可注入坏 hash、截断 blob、重复路径、悬空引用。
  • 支持在任意分区后模拟传输中断。

SessionContinuityFixture

  • 完成、运行中、待审批、失败、暂停的 Task。
  • 父子 Session、active leaf、compaction 与命令回执。
  • 同一 Session 从 A 导出到 B 的预期 RecoveryPlan。

RepositoryFixture

  • Git repo、dirty worktree、staged、branch、rename、binary。
  • Portable VCS snapshot/object/head。
  • 故意缺失 Git object / index 的降级样例。

PathMatrix

  • 大小写冲突、Unicode NFC/NFD、Windows 保留名、盘符。
  • symlink 越界、相对 symlink、junction 模拟。
  • 大小写敏感/不敏感 destination adapter。

HostSwitchHarness

  • Memory、Node TUI、Sandbox、Chrome Read-only。
  • 可改变 execution/test/git 能力和 toolchain version。
  • 每次导入记录 capability report 和 environmentId。

CrashInjector

  • 在 receive、validate、materialize、commit 四阶段崩溃。
  • 重启后检查 active/staging 状态。
  • 验证危险命令不自动重放。

15. 状态空间与属性测试

空间：
  capsule states = valid | corrupt | interrupted
  import phases = receive | validate | materialize | commit | active
  active tasks = none | model | tool | subagent | job
  environments = same | execution-missing | toolchain-changed
  destinations = empty | existing | read-only
  events ≤ 8

不变量：
  active Workspace 只能从 committed capsule 切换
  no-half-active = old generation ∨ complete new generation
  session refs ⊆ artifact refs ∪ historical-broken(refs explicitly marked)
  current evidence ⇒ fileHash matched ∧ environmentId matched
  interrupted(tool) ⇒ no automatic dangerous replay
  capsule visible path ⇒ WorkspacePath
  no Secret in manifest/session/artifact

属性测试

  • 随机分区/文件顺序不影响 root digest 规范化结果。
  • 任意阶段故障后 active generation 保持一致。
  • 任意路径输入不越出 Workspace root。
  • 任意环境指纹变化不能保持 current 测试证据。

变异测试目标

  • 删除 hash 校验。
  • 先写 active 再验证。
  • 忽略 dangling artifact。
  • 环境 fingerprint 永远相同。
  • 运行中命令自动重放。
  • 大小写 collision 静默合并。

18. 完成定义与确认项

维度可观测完成标准
完整性Capsule 所有分区和引用通过 hash/schema 校验。
连续性同 Workspace/Session 可跨宿主继续，不丢失用户工作。
恢复运行中操作安全终止并明确对账；不存在自动危险重放。
环境证据始终关联环境指纹和文件 hash；跨环境重新验证。
路径宿主只看到 WorkspacePath；Windows/Linux 规则测试通过。
原子性导入失败和崩溃都不会污染 active Workspace。
可扩展未来新客户端实现 HostTransport/Ports，无需重写 Capsule/Core。

确认 01

接受 Capsule 作为唯一迁移单位，包含 Project、AgentState、Repository、Artifact、Evidence、Environment 和可选 ClientState。

确认 02

接受运行中进程/PTY/网络/Secret 不迁移；导入后从安全边界恢复。

确认 03

接受跨宿主旧验证证据变为 stale，必须按新环境重新运行。

确认 04

接受 Host 运输不透明 bytes，Workspace 负责解释 Capsule，Core 不读取宿主平台信息做分支。
