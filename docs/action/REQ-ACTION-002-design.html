REQ-ACTION-002 / HARDENING DESIGN / 0.6.1

Action Result、审批票据与可观察性

修复 0.6.0 中 ActionResult 元数据在 Agent 工具边界丢失、审批仅存在于当前调用、二进制输出退化为文本以及缺少 Action 管理器的问题。

1. 范围

实现

  • ActionResult 元数据进入 ToolExecutionResult、Session row 和 UI。
  • 二进制 Action Artifact 存入 ArtifactStore。
  • 持久化 approval receipt。
  • Provider 可选幂等要求。
  • TUI Action Manager 展示状态、版本、风险和限制。

非目标

  • 不实现 TestReport 当前/过期证据（REQ-TEST-001）。
  • 不实现跨进程分布式审批。
  • 不增加通用 exec。
  • 不改变 Action Tool Schema。

4. Result 与 Artifact

ToolDefinition 增加可选 executeDetailed；旧工具继续返回 JsonValue。Action 工具通过 detailed 路径返回结构化 metadata。ToolExecutor 对输出 schema 只校验 value，再将 inline attachments 写入 ArtifactStore。

  • artifactIds 和新建 Artifact ref 合并，不去重丢失。
  • binary 数据以原 bytes 保存，MIME/kind/name 明确。
  • ConversationRow 保存可投影 metadata；模型 ToolResult 同时得到 output 与工具元数据。
  • metadata 不含 Secret；截断只影响模型可见文本。

5. 审批票据与幂等

ToolExecutor 在 approval 决策后写入 receipt。Receipt 包含 session/task/call/tool、risk、decision、actionDigest、approvalContext 和 timestamp。默认使用 HostStorage；内存宿主使用 Memory store。

HostActionDescriptor.idempotency: 'safe' | 'required' | 'never'

required + 相同 session/task/action/version/input/workspace generation
  → 返回第一次结果，不重复执行副作用

workspace generation / environment / input / Action version 变化
  → 新 scope，旧结果不复用

Remote abort 后迟到响应必须丢弃；调用只能返回 cancelled，不得在当前或后续请求中变成成功。

6. TUI Action Manager

新增 Actions route，Ctrl+Y 打开。列表从当前 HostActionRegistry 重新 discover，显示 Action ID、版本、available/degraded/unavailable、effects、risk、source 和 limitations。它只读，不直接执行危险操作。

7. 失败与恢复

ArtifactStore 缺失保留 metadata 和 attachment bytes 摘要，不声称已持久化
Receipt 写失败工具失败，不执行危险 Action
重复 idempotency key返回 cached result 并标注 replayed
Remote 迟到结果丢弃，不更新当前状态
Provider version 改变旧 idempotency cache 失效

8. 验收

  • Action metadata 从 Provider 到 UI 全链路保持。
  • 二进制 Artifact round-trip byte-equal。
  • approved/denied/cancelled 审批均有持久 receipt。
  • required idempotency 的重复调用只执行一次。
  • Late remote response 不会产生成功结果。
  • Action Manager 不暴露隐藏 Action，不泄露 Secret。
  • 旧 ToolDefinition 与现有测试保持兼容。
