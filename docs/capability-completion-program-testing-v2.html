每个阶段独立验证，但共享架构不变量：底座不由 Action 提供、Action 不可绕过审批、Evidence 必须属于当前 Workspace generation、跨端 Tool Schema 一致、无关模块不得依赖 Local Node Adapter。

1. 测试策略

每阶段必须证明

  • 能力契约和失败状态。
  • 至少一条真实用户旅程。
  • 模块边界没有新增反向依赖。
  • 上一阶段能力没有回归。

跨阶段不变量

  • Storage/FS/Clock/Crypto 不是 Action。
  • Action unavailable/denied 不 fallback shell。
  • Evidence 只验证当前 generation。
  • TUI/Headless/Chrome 同源组合。
