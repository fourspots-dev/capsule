1. 测试策略

三层判定

  • Portable 自己读取并理解真实仓库。
  • Portable 写出的文件由真实 Git 读取和校验。
  • 相同输入下 Portable 与 CLI 的规范化结果一致。

不能接受的假成功

  • 只在自己的 SnapshotVcs 中成功，真实 Git 无法读取。
  • 把 pack/index 当不透明 blob，无法 status/log。
  • CLI 缺失时自动禁用 Git。
  • hooks/filter 被执行或对象格式不支持时半写入。
P0：Git-compatible 文件被真实 Git 拒绝、Index 写入破坏 staged 状态、checkout 覆盖用户修改、执行 hook/filter、对象 hash 校验缺失，任一发生即阻止发布。

3. 测试夹具

GitRepoFixture

  • empty、single commit、branch/tag、dirty、staged、detached。
  • binary、rename、symlink、Unicode/CRLF。
  • loose objects 与 packfile 两种仓库。

GitOracle

  • 真实 git status/diff/log/show/rev-parse。
  • 只用于测试和可选 CLI 后端，不是运行时必需。
  • 规范化 author/time/path 后比较。

PureJsRuntime

  • 禁用 node:fs、child_process、native modules 和 git PATH。
  • 只提供 VFS、Crypto/Compression、Storage。
  • 证明 Browser/iOS 基线可运行。

PackFixture

  • pack v2、index v2、OFS/REF delta、多对象 pack。
  • 循环 delta、越界、错 hash、截断。
  • 真实 Git 生成样本。

12. 差分、属性与限制

不变量：
  OID = SHA1(type + ' ' + size + NUL + content)
  index path <=> valid WorkspacePath
  commit tree = staged snapshot
  worktree bytes unchanged by status/diff/log
  checkout failure => old HEAD + index + worktree preserved
  no hook/filter/process invocation in Portable backend
  unsupported feature => no partial state mutation

bounded property inputs:
  files 1..20
  paths with case/unicode
  tree depth <= 5
  delta chain <= 32
  commit DAG depth <= 20
ID场景预期
PGIT-095SHA-256 repo稳定 unsupported；不写 index/ref
PGIT-096unknown index extension只读或拒绝写，不丢失 extension
PGIT-097linked worktreev1 unsupported，不把外部 .git 路径带入 Agent
PGIT-098submodulegitlink/.gitmodules 可见；不自动拉取
PGIT-099LFS pointerpointer 保持；缺失 object warning
PGIT-100CLI 与 Portable 不共性只暴露 stable capability；高级 CLI 操作不改变 common tools

13. 发布门禁

100%

格式互操作

Portable 写出的每个必需仓库由真实 Git 读取通过。

0

宿主依赖

Pure JS E2E 不调用 git、node process 或 node:fs。

0

静默扩权

不支持项、hooks、filter、凭据不静默执行或丢弃。

门禁证据阻塞
Object/formatPortable fixtures + real Git fsck --strictOID/tree/index 不一致
Real repo readloose/pack repo status/log/show/diff无法读取常见 clone
Write interopPortable commit → git status/log/show真实 Git 拒绝或状态不一致
Pure JS E2E禁用 git/PATH/node processcommon subset 依赖宿主
Capsuledirty/staged/branch 跨宿主往返索引/历史/ref 丢失
Security恶意 object/pack/index/path/hook fixture越界、执行或半写入
ParityPortable vs CLI normalized golden核心状态不可解释地不同
