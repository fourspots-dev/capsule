1. 测试策略

核心问题

  • 样式语义和颜色降级是否稳定。
  • Panel 布局、焦点、滚动和空间预算是否可组合。
  • Markdown/代码/Diff 在异常输入下是否安全。
  • Reasoning 是否只展示 Provider 可见内容，并与 Waiting 区分。
  • 流式更新是否局部刷新、无闪烁且输入不阻塞。
  • 真实 PTY 下鼠标码、控制序列、resize 和 IME 是否正确。

测试原则

  • 不把截图或人工目测当作唯一证据。
  • 先断言 ScreenBuffer，再断言 ANSI 网格和真实 PTY。
  • Theme、Layout、Panel、Reasoning 使用纯函数/模型测试。
  • PTY E2E 不 mock Keymap、Composer、焦点或 Projection 对账。
  • Reasoning 测试必须区分 Provider-visible reasoning 与本地 Waiting。
  • 每种视觉结论都要有可在 CI 复现的 fixture。
分层顺序：Unit → ViewModel/Block → ScreenBuffer/Golden → Runtime Integration → Real PTY → State Space → Performance/Fault → Release。

4. 测试 Harness

Pure Render Harness

直接构造 ViewModel，输出 ScreenBuffer 和 ANSI；时钟、Session ID、Artifact 和 Theme 可固定。

PTY Harness

通过真实 PTY 启动 TUI，注入按键、粘贴和 resize；建议 devDependency 使用 node-pty。

Terminal Emulator

用 @xterm/headless 或等价解析器把 ANSI 还原成 rows×columns，断言光标、颜色、背景和裁剪。

Golden Normalizer

归一化时间、Session ID、Artifact ID 和动画帧；不得归一化颜色、边框宽度、焦点和换行。

8. 对话层级与原生光标

HIER 测试问题

  • 不同类型内容是否有稳定 gutter 和缩进。
  • 最终结果是否比过程日志更醒目。
  • 连续工具与嵌套列表是否形成视觉分组。

  • 光标是否由终端原生绘制并闪烁。
  • 光标绝对行列是否对应逻辑输入 offset。
  • IME 候选框锚点是否正确。

13. Panel、层级与光标状态空间

Theme =
  dark | light | mono
ColorDepth =
  truecolor | ansi256 | ansi16 | none
Session =
  A | B
Task =
  queued | running | waiting | completed | failed
Panel =
  conversation | reasoning | tool | diff | sessions |
  agents | status | command | approval
Focus =
  composer | transcript | overlay
Cursor =
  hidden | visible | composing | fallback
Reasoning =
  unavailable | waiting | streaming | complete | failed
Width =
  full | normal | narrow | emergency

主不变量：
  任意时刻只有一个焦点和一个活动 overlay
  Composer 永不被 Panel 越界覆盖
  非活动 Session 的 Reasoning 不进入当前 Panel
  Waiting 不生成 Reasoning 内容
  真实 reasoning 不被 Activity Thinking 重复
  Panel 关闭恢复原焦点、草稿、滚动
  Composer 聚焦时恰有一个可见光标
  光标 logical offset 与 visual row/column 双向可定位
  overlay/失焦时正文区域无残留光标
  User/Assistant/Work/Result 的 gutter 层级稳定
  Result 不被连续工具输出挤出当前回合
  P0/P1 状态在全部宽度可见
  扩展不能创建永久侧栏
  所有外部文本都不改变终端控制状态

建议先用组合模型覆盖 3 themes × 4 color depths × 5 task statuses × 9 panels × 3 focus × 4 cursor states × 5 reasoning states × 4 widths，再做 pairwise 降维；关键三元组必须全量保留。
