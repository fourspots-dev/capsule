TAB-11 真实 Chrome 执行目标验证

1. 在 about:blank 发起组工作区任务
2. Agent 创建 E2E Fixture 标签，形成组 G，executionTabId=Fixture
3. 用户切到组内 about:blank 标签，只更新 activeTabId
4. 发送“execution target smoke”
5. Agent 调用 read_page
6. 最终输出必须包含 Fixture 的 “Browser fixture ready”

该断言同时验证 DOM 字段、Session 映射和 ChromeBrowserProvider 的真实 working tab，而不是只看 UI 标记。若查看标签切换偷偷改变执行标签，read_page 会读到 about:blank，测试失败。

6. 验收标准

  • 打开任意标签，只能看到该标签自己的当前对话。
  • 切换标签后，对话、草稿、附件、审批和运行状态同步切换。
  • 旧标签任务在后台运行，不被新标签停止或污染。
  • Runtime/Gateway 重建后，仍在同一浏览器会话中的标签保持原 Session。
  • 完整浏览器重启后不误用旧 tabId；历史仍可从 History 打开。
  • Agent 工具无法绕过组边界；组内切换必须显式改变 executionTabId。
  • 用户仅查看其他组内标签时，不得改变任务执行标签。
  • 全量清理后没有旧 Snapshot、标签映射、Legacy 分组标题或残留 Projection。
