2. State equivalence

从一次 initial snapshot 开始，依次应用所有 SessionProjectionChange，最终 ProductProjection 必须与 `runtime.getProjection(sessionId)` 深度相等。覆盖文本 delta、状态、子 Agent、tool metadata 和终态。

3. 压力测试

Long text

至少 2,000 个 reasoning/message delta；检查每条 change 只含增量，不重复累计全文。

Many rows

创建 1,000+ rows；Side Panel 只构建最近 500 行 DOM。

Many sessions

8 个已持久化 idle Session；resident 数保持 ≤6，list/history 仍返回全部。

Disconnected debug

无服务端 ACK 时队列保持 ≤2MB，不阻塞任务。

6. Evidence

Observed 0.12.0 evidence: npm run check 458 passed / 3 skipped；Chrome E2E 10 passed；npm run verify:tui passed；真实 Chrome 执行 2,000 组 reasoning/answer delta 后，GC 后 renderer heap 增量为 0 MB。仅“看起来变快”不构成验收。
