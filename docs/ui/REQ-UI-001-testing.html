3. Detailed cases

Component output

  • settingsNavRow escapes label/value/action and emits one clickable row.
  • settingsForm emits the canonical wb-form class and optional id.
  • settingsSubpage emits the stage, title and back action.
  • Empty icon/control parts do not leave malformed wrappers.
  • Unknown custom control string remains explicitly owned by caller.

E2E interaction

  • Open Settings and compute nav row border/background.
  • Open Connections and verify text/password/textarea anatomy.
  • Open Remote Actions and verify URL/number radius and full width.
  • Open Capabilities and use back-runtime; then close Settings.
  • Repeat at 420x900 and 320x700; assert scrollWidth <= clientWidth + 1.
  • Capture screenshots for manual review; screenshots are evidence, not the only oracle.

5. Failure cases

  • Raw card/row returns: static gate fails with Contract path.
  • Browser default button border: E2E computed style fails.
  • Remote page input loses shared radius: E2E fails.
  • Subpage back action closes whole page: navigation E2E fails.
  • Narrow screen overflow: responsive E2E fails.
  • New requirement omits UI impact: template review catches it before implementation.
