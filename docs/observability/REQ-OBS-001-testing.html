TINYAI / EXECUTION DEBUG / TEST DESIGN

Debug Hub 测试设计

验证事件正确性、cursor 语义、服务认证、持久化、实时流、Chrome 出站上报以及无副作用边界。

1. 测试层级

Unit

事件 projection、redaction、cursor、dedupe、retention、transport queue。

HTTP Integration

真实 ephemeral server：认证、ingest、query、SSE、export、错误码。

Chrome E2E

真实扩展配置 Debug Service，执行任务，外部 Hub 收到事件。

Security / Fault

无 token、错误 token、恶意 key、慢消费者、断线重试。

3. Fixtures

  • Projection fixture：user → reasoning → tool → child → assistant 终态。
  • HTTP server 使用 port 0 和临时 data dir。
  • Chrome transport 使用可注入 fetch/clock。
  • Chrome E2E 启动真实 Hub 和 fixture model server。
  • 大事件、超 retention、过期 cursor、慢 SSE client 作为 fault fixture。
