边界与恢复

  • DEC title 或 file 的 ID 不一致时失败。
  • superseded DEC 没有 replacement 或 replacement 不回指时失败。
  • not_required 缺少 rationale 或 reviewedAt 时失败。
  • existing 引用 non-accepted ADR 时失败。
  • proposed 引用 non-proposed ADR 时失败。
  • 删除 ADR 但保留 DEC promotion 时失败。
