3. P1 — Virtual Environment Foundation

实现

MemoryFS、OverlayFS、PersistentFS、ArchiveFS、VirtualWorkspace、Virtual Shell、Unified Patch、Glob/Search、Snapshot VCS、Host Capability/Storage/Workspace Bridge。

边界

Agent 工具只访问 VirtualFileSystem；Patch 和 Search 不调用宿主 Bash/Git；Host 只处理存储、Bundle、Terminal、可选 Process/Network。

可复现证据

  • tests/virtual/vfs-contract.test.ts：Memory/Overlay/Persistent 同一契约。
  • tests/virtual/shell.test.ts：变量、引号、管道、重定向、逻辑组、VFS 内建命令、取消和不支持语法。
  • tests/virtual/patch.test.ts：修改/新增/删除、Expected Version/Hash、上下文冲突、多文件回滚。
  • tests/virtual/search.test.ts：Glob、include/exclude、regex/whole-word/context。
  • tests/host/host-bridge.test.ts：声明/实现一致性、缺失能力、未知/重复声明。

4. P2 — macOS TUI 与 Coding Loop

默认体验

1 行状态栏、1–6 行 Composer、主对话占满剩余空间；无永久侧栏。80×24、60×20、120×40 由 Presenter/Golden 级断言覆盖。

多 Session

Ctrl+K 列表、新建 Draft、搜索、切换、重命名、删除；每 Session 独立草稿、附件、滚动、选择、过滤和未读位置。

Agent 看板

任意 Profile 父子树、ACTIVE/ATTENTION/DONE 过滤、进入子 Session、返回看板、停止、Merge Preview/Apply。

Review

Ctrl+O 读取 Snapshot VCS Diff；有验证状态和风险时在同一临时 Review 视图展示。

运行证据

  • 真实 PTY 启动 dist/tinyai-tui.cjs，验证状态栏、Composer、Ctrl+K、N 新建、Ctrl+G、Esc 返回和双击 Ctrl+C 退出。
  • tests/tui/app.test.ts 覆盖发送、Session Draft、Agent 子 Session、Review 和退出语义。
  • tests/tui/session-controller.test.ts 覆盖 A→B→C 迟到帧和后台 Session 不被停止。

7. P5 — 扩展基线

  • Projection 事件增加 sessionId、logEpoch、可选 subscriptionId，快速切换时可靠丢弃旧帧。
  • HeadlessRuntimeClient 只依赖通用 RuntimePort，不导入 Chrome、TUI 或 Node API。
  • Headless 集成测试覆盖 connect、list、command、rename、subscribe、projection update、stop、delete。
  • typecheck:core 与 check:boundaries 证明 Core/Platform 不反向依赖 UI/Chrome。
  • iOS 未实现，只保留端无关协议和 Workspace Bundle 扩展边界。

8. P6 — 通用子 Agent 与 Workspace Fork

  • Profile 是配置数据，不存在固定 Researcher/Reviewer 枚举。
  • ChildTaskSpec 和 ChildTaskProjection 持久化父 Session、父 Task、Profile、执行模式和 Workspace 状态。
  • 子 Agent 在 Overlay Fork 编辑，父 Workspace 保持只读；Preview 输出文件、Patch、冲突和父/子 Hash。
  • 父 Workspace 在 Fork 后被修改时，Merge 明确阻断；只有显式 Apply 才写入父 Workspace并建立 checkpoint。
  • TUI 子 Session 使用同一主 Runtime，因此父/子都接收实时 Projection，切换不会断开执行。

9. P7 — 生产加固

Verification Gate

Runtime 可注入 CompletionGuard。TUI 在有文件写入但没有成功 exec/job verification 时返回 VERIFICATION_REQUIRED。

Coding Benchmark

无宿主 Bash/FS 的 fixture 完成 Search → Patch → Verify → Final，且最终文件与工具证据都正确。

Bounded Soak

100 checkpoints、50 并发 Job、10k 文件 Search、10k Projection update 在预算内完成。

P7 标记为 CONDITIONAL：真实模型 smoke 需要环境凭据；8 小时 Soak 与 1GB Workspace 属于发布前长测，本轮只执行了加速、有界版本。
