2. Architecture Completeness

  • Source of truth: package.json。
  • Consumer: unpacked extension、packaged ZIP、Chrome extension card。
  • Persistence: 无 Schema 变化。
  • Cleanup: 删除手工维护的 manifest 版本作为发布事实。
  • Evidence: unit checker、build artifact inspection、Chrome E2E。
