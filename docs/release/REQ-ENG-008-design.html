Chrome 扩展版本同步

REQ-ENG-008 · target 0.9.1 · 修复 unpacked extension 仍显示 0.1.0 的发布一致性问题。

1. Scope

package.json.version 继续作为唯一产品版本源。构建时同步 extension/manifest.json.version，打包 ZIP 使用同步后的 manifest。CI 校验两者一致。

2. Architecture Impact

SurfaceChange
Release scripts新增 manifest sync 与 check 脚本
Extension package显示产品版本；manifest 内容不变
Runtime/Core无变化
Existing extension storage无迁移
Chrome reload 读取同一 extension 目录时，扩展卡片版本、Side Panel 代码与 package 版本保持一致。

3. Build Flow

package.json.version
  → sync-extension-manifest-version.mjs
  → extension/manifest.json
  → extension reload / tinyai-extension.zip

CI:
check-extension-version.mjs
  → package.version === manifest.version

4. Failure Behavior

缺少 manifest、版本不是三段式、JSON 损坏或版本漂移均使构建/检查失败，不生成一个版本身份错误的扩展包。

5. Acceptance

  • 立即刷新后 extension/manifest.json.version 为 0.9.1。
  • npm run build 自动同步。
  • npm run extension:check 捕获漂移。
  • ZIP 内 manifest 版本一致。
  • Chrome E2E 继续通过。
