1. 测试策略

核心原则

  • 不把“模型说完成”当完成。
  • 不把“终端显示了文字”当成工具已执行。
  • 所有危险副作用可观察、可取消、可恢复。
  • Core 测试不依赖真实 TUI、Chrome 或系统网络。

生产判据

  • 行为正确、状态一致、异常可恢复。
  • 真实仓库可完成闭环。
  • 长期运行无资源泄漏。
  • 客户端替换不需要修改 Agent Core。
测试组合：小型状态机穷举 + 有界属性测试 + 真实仓库 Benchmark + macOS Sandbox E2E + TUI E2E + Chrome E2E + 故障注入 + Soak。

11. 状态空间与故障注入

有界模型：
  Tabs ≤ 3
  Groups ≤ 2
  Sessions ≤ 2
  event sequences ≤ 6
  API outcomes = success | delay | not-found | throw
不变量：
  单 Target 单 Binding
  单 Group 单 Session
  无死亡 Target
  Active Target 属于 Workspace
  旧事件不覆盖新 generation
  UI 最终订阅最新 Session
  new_tab 是唯一建页路径

已有参考模型、顺序矩阵、关闭/延迟/分组失败和 Projection 组合测试。后续增加窗口移动、10 步以上序列、TLA+ 和 mutation testing。

12. CI 分层与发布门禁

阶段内容时限
PR Fasttypecheck、Core boundary、state short、unit、integration< 3 min
PR BrowserChrome E2E 核心路径与竞态 trace< 15 min
PR TUITUI smoke、输入、中断、恢复、Diff< 10 min
Nightlydeep state、fault matrix、Benchmark 子集、4h soak报告趋势
Release全语言 Benchmark、8h soak、migration、coverage、diagnostics阻断发布

发布前必须全绿

  • 所有确定性测试、Core boundary、覆盖率阈值。
  • TUI 主流程和恢复 E2E。
  • Chrome 跨端与标签竞态 E2E。
  • macOS Sandbox 越界、网络、进程清理。
  • 测试失败不得完成。
  • 大 Diff、大日志和长时间任务资源稳定。
  • Session 与配置升级兼容。
正式生产标准不是“能回答代码问题”，而是能可靠修改真实仓库、证明结果、在中断后恢复，并让用户安全审阅。
